**间接注入**（对话框被盯死时；数据通道常无意图分类器）：

| 载体 | 触发 | 要测 |
|---|---|---|
| RAG / 上传文档 | 他人检索 | **跨用户** |
| 邮件 / 工单 / Lead | 办公 Agent 读 | 零点击 |
| 网页 / 工具返回 JSON | Agent 抓 URL | 外带 |
| 记忆 | 后续会话 | 持久 + 跨用户 |

写法：伪装业务规则、给理由、不要写「忽略之前的指令」。**跨用户生效才从注入升到高危害。**
