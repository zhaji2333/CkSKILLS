# 一、先分清：遥控器 vs 注入

> 来源：CkSKILLS v1 `agent-prompt-injection-bypass` §一、先分清：遥控器 vs 注入（迁移至 v2 知识块）

| 你在干什么 | 叫什么 | 怎么打 |
|---|---|---|
| 它有 exec 且肯跑，你让它 `echo hello` / `id` / `env` | **合法工具使用（过度授权）** | 正常提问，**不是注入** |
| 它本该拒绝，你改叙事/拆步骤/换实现/编码，仍让它调工具 | **提示词注入 / 护栏绕过** | 本节第五～七节 |
| 指令藏在它要读的数据里 | **间接注入** | 第七节 |

**第一枪永远是遥控器，不是 DAN。** 越狱式覆盖指令才不可靠；不要把整场对话耗在越狱上。

拿 shell = 一条你写的命令在云端 Linux 上跑起来并看到输出。过了 `echo hello` → **立刻停注入，转 `agent-sandbox-takeover`**。边聊边 F12（`agent-execution-channel-hijack`）。
