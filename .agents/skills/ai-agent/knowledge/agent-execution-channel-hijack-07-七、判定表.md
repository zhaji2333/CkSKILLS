# 七、判定表

> 来源：CkSKILLS v1 `agent-execution-channel-hijack` §七、判定表（迁移至 v2 知识块）

| 现象 | 结论 | 下一步 |
|---|---|---|
| 对话框拒，F12 有 `/exec` | 模型拦、平台有 | 路径 B |
| 有接口但要签名 | 签名在前端 | 拆 JS |
| 401/403 | 平台也拦 | 换口 / 换租户参数 |
| body/path 有 sandbox_id 能改 | **跨租户候选** | 第三节 |
| 缺参 400、带 token 才 401 | 鉴权在校验后 | 补参 + 换 id |
| 只有对话口 | 执行由模型驱动 | A 或 C |
| 拒绝后状态变化 | 解耦缝 | 第五节 |
| 网关口无鉴权或认钥 | L1/L2 | 进沙箱追 L3 |
