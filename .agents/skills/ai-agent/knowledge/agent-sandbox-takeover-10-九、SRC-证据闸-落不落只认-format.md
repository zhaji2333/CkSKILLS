# 九、SRC 证据闸（落不落只认 format）

> 来源：CkSKILLS v1 `agent-sandbox-takeover` §九、SRC 证据闸（落不落只认 format）（迁移至 v2 知识块）

| 声称 | 最低证据 | 锚 |
|---|---|---|
| 跨租户影响全用户 | 自己的会话 + 换他人 id 后出现他人正文/PII/执行 | 高或严重（有执行/进号走严重） |
| 网关劫持无感 RCE / 肉鸡 | L3：另一会话或客户端执行了注入内容 | 严重；停在 L1/L2 不够 |
| 凭据 | 假值对照 + 认钥枪带出身份或列表 | 高；进了别人号才严重 |
| 组件未授权 | 真实执行或真实业务数据 | 按数据面 |
| 沙箱逃逸 | 宿主文件或 docker.sock 控运行时 | 严重 |
| 计费双逻辑 / 无限额度 | 默认不落盘，除非动到他人资源或资金 | 拿不准不写 |

匿名闸：打通那包有 Cookie/会话 → 不写「匿名」。认钥闸：抄到钥不算洞。
