# 八、七大危害面（认 → 打 → 算成 → 假点）

> 来源：CkSKILLS v1 `agent-sandbox-takeover` §八、七大危害面（认 → 打 → 算成 → 假点）（迁移至 v2 知识块）

每面打穿或证伪再换下一面。**算成**必须能回答「比基线多了谁的什么」。

### 8.1 组件未授权

| | |
|---|---|
| **认** | `ss -tlnp` / 进程树里的解释器、命令执行服务、jupyter、envd、gateway、MCP、VNC、CDP、sshd |
| **打** | 上节冒烟；无 token 打 `/execute` `/envs` `/json/version`；回环抬全网卡的先打 |
| **算成** | 无认证执行了命令，或读出真实业务/会话数据 |
| **假点** | 健康检查 200、空 JSON、配置枚举。**能创建 key ≠ 能调用资源**。**自己挂的 ttyd/cloudflared 不是厂商未授权组件** |

### 8.2 敏感凭据

| | |
|---|---|
| **认** | env、`/proc/1/environ`、`/etc/*-config`、openclaw.json、SA Token、s6 env、chat-history |
| **打** | 抄到后 **假值对照**；认钥枪必须带出身份或列表（云 SDK 列 bucket/项目、模型网关返回模型列表、K8s `kubectl auth can-i`） |
| **算成** | 生产认了，且带出身份/列表。进了别人号或改了别人的绑 → 另开「接管」口径 |
| **假点** | 只抄到字符串；占位/过期；真假同一句错。**没过认钥闸不写报告**（`../../../../rules/40-evidence-report.md`） |

### 8.3 沙箱内提权

| | |
|---|---|
| **认** | 非 root +（`sudo -n -l` / setuid / CapBnd 含 SETUID/SETPCAP / 文件 capability） |
| **打** | `sudo -n id`；CapBnd 有 SETUID 才扫 setuid 文件 |
| **算成** | 从低权变成 root 或等价 |
| **假点** | 已经是 root 还报提权；CapEff=0 就判「不能提」 |

### 8.4 沙箱逃逸

| | |
|---|---|
| **认** | 见第七节。真 VM 不要硬找容器逃逸 |
| **打** | sock → 宿主容器；块设备 → debugfs；提权后再评估挂载 |
| **算成** | 读到宿主文件，或控到运行时（docker.sock 起容器） |
| **假点** | 只在容器里 `cat /etc/hostname`；只证明 seccomp=0 但没出宿主 |

### 8.5 跨租户（运行时层；HTTP 层在 `agent-execution-channel-hijack`）

必须有 **自己的对象基线 → 换成他人标识 → 对得上他人字段**。

| 形态 | 打法 |
|---|---|
| 共享可写内部服务 | 包缓存 / Artifactory / 网关对象存储：自己写一条属性或文件，用第二个会话读到 |
| 共享技能库 | 多租户只读挂载的 `skills` / `official_skills` / `common-skills`：若可写或能换路径写入 → 一次投毒多租户（升 8.8 L3） |
| per-user JWT | 配置里的 `user_id`/`chat_id` 换成回包里抄的他人 id，打内部 API |
| NFS / 会话目录 | 路径里的租户前缀换成邻号，看是否可读他人 workspace / 对话 |
| 服务发现 | DNS / API 列出其它租户 pod/sandbox，打过去 |
| CDP / 浏览器数据 | `0.0.0.0` 上的 CDP 读别人 `chrome_data` |

| | |
|---|---|
| **算成** | 出现 **另一个人** 的业务正文 / PII / 执行结果 / 登录态 |
| **假点** | 空列表、公开配置、只换了 id 回了自己的数据、没有对照账号就报「全用户」 |

「影响全用户」= 这个洞的对象空间是平台上任意租户，不是你测了两个人就写全用户——但 **对象空间无租户绑定** 即可按全用户写危害（举例仍用打穿的那一两个）。

### 8.6 集群横移

| | |
|---|---|
| **认** | SA Token + `:6443` 可达，或已 ESTABLISHED 到 apiserver |
| **打** | `kubectl auth can-i --list`；列 ns / pod；RBAC 决定上限 |
| **算成** | 能操作他 ns 的资源，或读到他 ns 的 secret |
| **假点** | token 在、6443 通，但 RBAC 只有本 pod 只读——记线索，不报集群沦陷 |

### 8.7 内网横移

| | |
|---|---|
| **认** | Q4 矩阵里 401/403 秒回的内网、IMDS、9.x/100.x、已有长连接 |
| **打** | 有钥走认钥；无钥走未授权中间件（转 `ssrf-internal-network` / `cloud-infra-supply-chain`） |
| **算成** | 打到内网服务的真实数据或执行 |
| **假点** | 超时当「不通」；401 当失败后不再用钥 |

### 8.8 网关劫持（无感 RCE / 肉鸡只在 L3）

云端自研 AI 网关 ≈ 模型调度 + 任务分发 + 容器/会话管理。认：env 的 baseUrl、`ss` 里的 18789/18791、明文 80 上的 `/llm`、进程名里带 gateway / 控制面 / 内部鉴权代理字样。

```
L1 未授权：GET 管理面 / 模型列表 / 健康检查出真实配置或能调推理
L2 认钥：沙箱内 key 能调网关，假 key 被拒（生产认了）
L3 下发：你能改/注入网关响应或全局配置，且另一会话或在线客户端真去执行
```

| | |
|---|---|
| **算成 L1/L2** | 未授权管理或认钥成功 → 按数据/钥的真实权限写危害，**不要写无感 RCE 全用户** |
| **算成 L3** | **第二个会话或客户端执行了你注入的指令**（命令落地、工具被调）。这才是「无感 RCE 全部在线用户 / 客户端当肉鸡」 |
| **假点** | 明文 HTTP 只证明可窃听；管理面 200 只证明未授权；单会话能调网关 ≠ 能投毒全部在线用户 |

L3 常见落点（有再打，没有标 N/A）：全局 system/tool 配置可写、共享技能库/MCP 多租户加载、你已在网关路径上可改响应（同主机/同网段 MITM）、控制面能给任意 `sandbox_id` 下发 exec。
