# 二进制与固件逆向实战

> 面向**真实授权评估**：IoT/嵌入式设备、服务型二进制、固件模块的授权绕过、凭据泄露与内存安全。工具：`objdump`/`readelf`/`strings`/`checksec`/python(`pwntools`,`unicorn`,`capstone`)；无 gdb 时用 unicorn 模拟 + pwntools 远程交互。

## 一、先分类（30 秒）

| 形态 | 判断 | 打法 |
|---|---|---|
| 服务型 ELF（TCP/Unix socket） | `nc ip port` 有 banner/HELP | 找命令集（HELP/DUMP/EXPORT/LIST/COPY/SET*/GET*），分析协议与内存操作 |
| 设备/固件授权模块 | 题面/环境给出"从固件提取的可执行文件" | 静态逆向找授权码校验、许可证算法、内置密钥 |
| 固件运行时模块（打包数据） | 有自解密/VM/加密数据段 | 还原解密流程，提取设备凭证 |
| 跨平器授权客户端 | 启动要求 license key | 逆向校验逻辑，构造合法 key 或跳过校验 |

**必做**：`file`、`checksec`、`strings -a -n 4 | grep -iE "license|serial|credential|key|secret|token|pass"`；再看 `objdump -d` 的 `main` 与校验函数。

## 二、信息泄露类（最快拿到凭据）

| 症状 | 打法 |
|---|---|
| BUILD/DUMP/EXPORT 类指令回显未初始化缓冲区 | 直接触发，看回显是否带出结构体/密钥/凭据片段；结构体未清零时敏感数据在相邻内存 |
| 按"请求长度"回显数据（heartbeat 类） | 声明长度 ≫ 实际载荷 → 越界读；敏感数据常在固定偏移（如 0x1000 附近） |
| 缓存/历史列表（HIST/PEEK/LIST） | 先触发容量淘汰（PUT 满 capacity）→ 淘汰项可能含预置凭据 |
| 格式化字符串 | `%s`/`%p`/`%x` 读栈；`%n` 写 |
| 越界读 | 超长 name/key 让 `%s` 读到相邻敏感数据 |

## 三、内存破坏类（写入型）

| 症状 | 打法 |
|---|---|
| COPY/WRITE 带偏移参数、无边界检查 | 负偏移或超长写覆写 guard/length/secret 判定变量，再触发导出指令 |
| 栈缓冲溢出（无 canary/NX 关闭） | 覆盖返回地址 → ROP/ret2shellcode；有 PIE 先泄露基址 |
| 堆溢/UAF | 看分配器版本与 free 时机；老 glibc 走 tcache/unsafe unlink |
| 整数溢出 | 短分配长拷贝；长度字段回绕 |

**验证**：本地 pwntools 复现 → 授权目标上打 → 以读取到的凭据/命令输出作为证据。

## 四、固件/ELF 静态逆向

1. **授权码/常量**：rodata 里 XOR 表（`xxd` 找重复模式）；授权码常 = 常量 XOR 单字节（0x4b/0x3c/0x37/0x5a 这类值逐个试）。
2. **状态机**：`objdump -d` 找跳转表；状态转移表常在 rodata（16×4 之类）；用 python 模拟输入校验，构造满足条件的 key。
3. **keystream/加密**：PJW/djb2/FNV1a 哈希派生；RC4/TEA/XOR 链；`unicorn` 模拟自解密 shellcode；注意 decoy（自研 VM 只打印占位输出可能是生成器/逻辑缺陷，不等于不存在有效路径）。
4. **Go stripped**：用 `debug/gosym` 或手写 pclntab 解析恢复 `main.*` 函数名。
5. **ARM/MIPS 固件**：capstone 反汇编；注意大小端与移位。

## 五、真实环境的常见坑

- **本地回退路径返回演示凭据**：程序在主路径失败时打印占位/演示值，真实凭据由主路径在读取本地授权文件后输出——需让主路径走通（正确 key/口令/环境）才能得到真实值。
- **隐藏管理接口**：二进制里可能有未公开的命令/路由（如 `B4CKD00R` 类隐藏命令、`/check` 类校验表单），字符串与命令派发表里能捞到。
- **凭据读取位置**：授权文件、配置文件、环境变量（`/etc/license*`、`/var/lib/<app>/*credential*`、`/root/.<app>/`）——逆向确认路径后针对性读取。
- **利用后取证**：以"能读取设备凭证/执行命令"为证明，不写入持久化、不改设备状态。

## 六、假点

- 解出的是回退/演示凭据；主路径未走通。
- 溢出导致崩溃但无回显/无控制流劫持 = 未证明可利用。
- 只在本地复现、授权目标上不可达 = 记录环境约束，不作为结论。
