# 二、失败升级路径（Level 1-7）

> 来源：CkSKILLS v1 `waf-bypass-techniques` §二、失败升级路径（Level 1-7）（迁移至 v2 知识块）

```
Level 1: 编码绕过
  → URL编码/双重编码/Unicode/十六进制/HTML实体/Base64

Level 2: 变形绕过
  → 大小写混合/双写/注释插入/空白符替换/等价函数

Level 3: 逻辑绕过
  → 换HTTP方法/换Content-Type/换参数位置/利用解析差异

Level 4: 协议层绕过
  → HTTP走私/分块传输/管道化/WebSocket升级

Level 5: 换入口点
  → 同功能的其他接口/旧版本接口/移动端接口/内部接口

Level 6: 组合利用
  → A接口的信息泄露 + B接口的弱校验 = 完整攻击链

Level 7: 时间维度
  → 并发/竞态/延时/定时任务触发
```

**判断规则：下"无漏洞"结论前，把适用维度过一遍并写明否定证据；不硬性要求凑到某一层。**
