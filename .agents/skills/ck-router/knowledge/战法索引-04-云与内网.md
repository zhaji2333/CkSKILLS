# 战法索引 04 · 云与内网

> 详细方法论：`cloud-infra/knowledge/`、`web-ssrf-render/knowledge/`、`ai-agent/knowledge/`。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| 云主机 Web 应用有 URL 抓取/代理/预览 | SSRF 打元数据：`169.254.169.254/latest/meta-data/iam/security-credentials/`、`100.100.100.200/latest/meta-data/`、`http://imds:8080` 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 回显 role 名与 AccessKey/Secret | 代理白名单且元数据也 403 |
| `/api/status`、`/debug`、`/actuator` 泄露内网地址 | 抄出 `metadata_endpoint`/`internal-api` 等主机名，用 SSRF/内网访问直达 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 拿到内网服务配置/管理 token | 只是健康检查无敏感值 |
| 对象存储 path-style 匿名可读 | 匿名 list 桶 → 读 README 找内部桶名 → 列内部桶 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 内部桶列出并读到凭据/flag | 仅公开桶；内部桶 403 |
| 云函数/Serverless 门户暴露 `/api/functions` | 无认证 GET 函数列表 → 读 `<fn>/config` 环境变量 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 环境变量/配置中的 DB 密码、密钥、令牌 | 配置接口要登录 |
| 云存储临时凭证门户（SAS/STS） | 无认证申凭证；用 container 级操作列桶；越权读 secret 桶 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 列出并读到内部容器对象 | 凭证范围仅本人前缀 |
| 云身份平台/OIDC/设备码 | 设备码流程不校验用户授权直接发 token；JWT payload 里找敏感字段；JWKS 可上传则自签 见 `../../web-auth-access/knowledge/oauth-jwt-test.md` | 拿到 admin/GlobalAdmin token | 有用户同意步骤且强校验 |
| 对象存储网关/身份联邦 | 上传自建 JWKS 到站内受信路径（jku 用 /files/ 前缀）→ 自签 HS256 换 STS → 读 tfstate 拿 root 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 换到高权凭证并读敏感桶 | jku 白名单固定站外不可控 |
| 1Panel/BT/Grafana/Zabbix/Jenkins 等运维面板 | 默认口令/安全入口码（EntranceCode=base64(entrance)）→ 面板 API 文件读取/终端/计划任务 见 `../../cloud-infra/knowledge/cloud-infra-supply-chain-01-一、运维-管理类场景表-全景.md` | 面板 API 读出 flag 或执行命令 | 强口令+IP 白名单 |
| Apache OFBiz / HugeGraph / GeoServer / 中间件 | OFBiz 默认 admin/ofbiz → EntitySQL/Content Manager；HugeGraph 未授权 Gremlin 改线程名；GeoServer GetPropertyValue exec 见 `../../cloud-infra/knowledge/中间件与产品CVE实战.md` | 未授权 RCE/读文件 | 已打补丁；接口下线 |
| K8s/Docker API 暴露（2375/6443/10255） | 未授权 API 列 pod/exec；ServiceAccount token 打 apiserver 见 `../../cloud-infra/knowledge/cloud-infra-supply-chain-03-三、云环境专项-14-4.md` | 集群内执行/取 secret | 只有只读 metrics |
| Redis/rsync/FPM/AJP/YARN/2375 公网可见 | 未授权写计划任务/SSH key；FPM/AJP 打 FastCGI/Tomcat 见 `../../cloud-infra/knowledge/info-leak-test.md` | 拿到 shell/读文件 | 有认证；只读端口 |
| CI/CD 泄露 token/仓库权限 | `.git/config`、Actions secret、tfstate、制品库凭据 见 `../../cloud-infra/knowledge/cloud-infra-supply-chain-05-五、供应链安全-L类.md` | 用 token 拉源码/发布 | token 已过期/只读 |
| AI/Agent 平台有对话口 + 工具列表（bash/code_exec） | 不登录打对话口让它执行命令；或云助手 whoami/对话口 见 `../../ai-agent/knowledge/agent-tool-exec-test.md` | 命令 stdout 回显 | 只口头说执行；沙箱 uid 不算 |
| 云 IDE / Codex 系编程台 | 弱口令 → `/codex-api/rpc` command/exec 见 `../../ai-agent/knowledge/cloud-ide-codex-rce-chain.md` | RPC 执行命令/读 env | 需登录且无默认口令 |
