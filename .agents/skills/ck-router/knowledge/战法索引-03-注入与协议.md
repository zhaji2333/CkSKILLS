# 战法索引 03 · 注入与协议

> 详细方法论：`../../web-injection/knowledge/`、`../../web-api-protocol/knowledge/`、`../../web-waf-bypass/knowledge/`。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| 登录页恒 500 / 报错页吞异常，但功能像有 DB | 时间盲注：`username=x' OR IF(1=1,SLEEP(0.25),0)-- `，对比响应时间 见 `../../web-injection/knowledge/injection-vulns-04-四、SQL-注入绕过技术.md` | 时间差稳定（多次重复可复现） | 网络抖动偶发；WAF 恒 500 |
| 列表筛选参 + 回包有 `total` | 布尔差分：假条件 vs 真条件看 total 变化；先假后真，恒真只打一枪 见 `../../web-injection/knowledge/injection-vulns-02-二、常见场景清单-搜索-查询类.md` | total 从 0 变海量且第一条是他人数据 | 只影响本页排序；total 不变 |
| 详情/查询参拼接 SQL | 报错注入/UNION 列数对齐；`' UNION SELECT ...-- ` 见 `../../web-injection/knowledge/injection-vulns-04-四、SQL-注入绕过技术.md` | 回显 DB 内容 | 预编译；只回固定错误 |
| JSON 查询条件可控 | NoSQL 操作符 `{"$gt":0}`/`{"$ne":null}`/数组绕过 见 `../../web-injection/knowledge/injection-vulns-02-二、常见场景清单-搜索-查询类.md` | 绕过查询条件拿到他人数据 | 后端类型强校验 |
| 命令执行点（ping/curl/文件名/导出） | `$(...)`、反引号、换行 `%0a`、`&`；分号被拦就换分隔符/编码 见 `../../web-injection/knowledge/injection-vulns-05-五、命令注入绕过技术.md` | 命令回显/外带成功 | 白名单参数、无 shell |
| 模板渲染（Jinja2/Twig/Freemarker/Velocity） | `{{7*7}}`→49 确认；再打 `config.__class__.__init__.__globals__['os'].popen(...)` 见 `../../web-injection/knowledge/injection-vulns-01-一、漏洞类型全景.md` | 命令执行读 flag | 沙箱模板；输出被转义 |
| 表达式注入（SpEL/OGNL/EL/MVEL/Groovy） | `T(java.lang.Runtime).getRuntime().exec(...)`/`${...}` 见 `../../web-deser-xxe/knowledge/el-injection-test.md` | 命令执行 | 表达式沙箱 |
| 请求头被用于路由/信任（Host/XFF/X-Original-URL） | Host 注入重置链接；`X-Forwarded-*` 绕过 ACL/缓存；路径覆盖头 见 `../../web-api-protocol/knowledge/http-host-header-test.md` | 重置链接指向你的域/绕过限制 | 服务端不信任该头 |
| 网关/CDN 前后端解析不一致 | CL.TE / TE.CL 走私；分块/压缩体绕过检测 见 `../../web-api-protocol/knowledge/http-smuggling-test.md` | 打到后端隐藏路由/绕过 WAF | 单层直连无代理 |
| 缓存可命中个人页/API | 缓存欺骗偷会话页（`.css`/`;.jpg` 后缀）；缓存键投毒 见 `../../web-api-protocol/knowledge/cache-poisoning-test.md` | 未登录拿到他人会话页/数据 | 缓存键含 Cookie；不缓存 |
| URL 抓取/代理/预览/回调入口 | SSRF：内网 IP、十进制 IP、`@`/`\@` 解析差异、302 跳转、DNS 重绑定、metadata 见 `../../web-ssrf-render/knowledge/ssrf-test.md` | 回显内网服务/metadata | 出网白名单且内网也拦 |
| SSRF 入口存在但私网被拦 | 十进制 IP（127.0.0.1→2130706433）、`0x7f.1`、`[::ffff:127.0.0.1]`、短域名、`internal-api` 主机名 见 `../../web-ssrf-render/knowledge/SSRF内网实战.md` | 打到内网服务响应 | 解析层也做私网校验 |
| 有公开 GOPROXY/代理功能 | 模块路径写成自己的域做 `?go-get=1`，用 hg 跟 VCS；或代理 `targetUrl` 打元数据 见 `../../web-ssrf-render/knowledge/ssrf-test.md` | 回显元数据/临时凭据 | 代理对匿名关死；元数据也 403 |
| WAF 拦住常规 payload | 按 Level 维度换层（编码→变形→逻辑→协议→换入口→组合→时间，可跳层） 见 `../../web-waf-bypass/knowledge/waf-bypass.md` | 绕过并拿到同样效果 | 换层后仍被拦且无等价入口 |
