# 战法索引 05 · 客户端与前端

> 详细方法论：`web-xss-frontend/knowledge/`、`mobile-app/knowledge/`、`web-api-protocol/knowledge/`。
> 前端硬编码密钥一律先当"未授权接口的钥匙"用，见 `../../web-recon/knowledge/js-reverse-guide.md`。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| 中间跳转页/登录回跳吃 `target`/`url`/`redirect_uri` | `javascript:`/`data:` 伪协议；白名单用 `@`、`\`、`//`、子域后缀绕过 见 `../../web-xss-frontend/knowledge/xss-frontend-security-03-三、跳转型-XSS-专项-🔴-优先测试.md` | 同源执行 JS / 开放重定向升级 XSS | 只允许 http(s) 且域严格 |
| 评论/昵称/搜索回显/Markdown 渲染 | 存储型/反射型 XSS；AI 输出渲染无净化 见 `../../web-xss-frontend/knowledge/xss-test.md` | 脚本执行/会话窃取 | 全转义 + CSP 严格 |
| 管理端/客服端有富文本 | 存储型 XSS 打管理员 bot（举报/反馈/工单） | bot 带着管理员会话执行 | 无 bot；CSP 阻断 |
| 前端写死 appId/appKey/secret/AK/SK/签名盐 | 提取后直接调接口；签名盐重算 sign 见 `../../web-recon/knowledge/js-reverse-guide.md` | 未授权调接口拿到数据 | 密钥是占位符/已失效 |
| JS 里写死 CI token / GitHub token / 对象存储永久键 | 用 token 拉仓库/发布/读桶 见 `../../web-recon/knowledge/recon-methodology.md` | 读到源码/内部制品 | 只读公开范围/已吊销 |
| API 只校验自定义头（`User-Id`/`X-Api-Key`） | 头值从 JS/安装包提取，换用户 id 打接口 见 `../../web-auth-access/knowledge/authbypass-test.md` | 他人数据 | 头值绑定会话 |
| SPA 前端路由守卫做权限 | 直接改前端路由/调后端 API（前端权限≠后端权限） 见 `../../web-auth-access/knowledge/auth-access-control-02-二、前端鉴权绕过-路由守卫绕过.md` | 访问管理接口成功 | 后端也校验 |
| postMessage 有 `*` 目标/无 origin 校验 | 构造消息触发 DOM XSS/敏感操作 见 `../../web-xss-frontend/knowledge/xss-frontend-security-05-五、XSS-绕过技术.md` | 跨源执行/拿数据 | 校验 origin 且白名单 |
| 小程序/H5 登录口吃 `openId` | 换 openid 登录他人；或未登录 loginByOpenId 见 `../../mobile-app/knowledge/miniprogram-security-01-快速开始-5-分钟出第一个接口-凭证.md` | 登入他人账号 | 服务端绑定会话/签名 |
| 小程序云开发/云函数有匿名登录 | 匿名 session 打数据源函数/低代码接口 见 `../../mobile-app/knowledge/miniprogram-security-01-快速开始-5-分钟出第一个接口-凭证.md` | 列表/详情出他人数据 | 权限规则严格 |
| Electron/CEF 自定义协议参数有 url/open | 协议里填外站页，页上探 `require`/`process` 后 exec 见 `../../web-xss-frontend/knowledge/xss-frontend-security-08-八、Clickjacking-专项.md` | 本机命令执行 | 协议只开自家域；沙箱死 |
| 客户端/桌面端渲染用户可控 HTML | 存储 XSS → 客户端 RCE（有桥/协议升级） 见 `../../web-xss-frontend/knowledge/xss-test.md` | 客户端执行命令 | 只在浏览器弹 |
| 有状态变更的写操作 | CSRF：无 token/可预测 token/GET 写 见 `../../web-xss-frontend/knowledge/csrf-test.md` | 以受害者身份完成写操作 | SameSite 严格 + token |
| CORS 配置回显 Origin + 凭据 | 资料保留；真实 SRC 默认不单独立项（`rules/20`） 见 `../../web-xss-frontend/knowledge/cors-test.md` | — | — |
| 分享页/发布页有 artifactMap/nodeId 等指针 | 不登录打发布域 pagechunk 读全文 见 `../../web-auth-access/knowledge/idor-test.md` | 他人文档全文 | 只读到已发布快照 |
| H5/落地页写死演示号/产品号 | 用演示号当钥匙打未登录业务口；或换 openid/uid 见 `../../web-auth-access/knowledge/authbypass-test.md` | 列表出现他人数据 | 演示号只读公开内容 |
