# 战法索引 08 · 内网与域

> 用法：内网/域场景先扫本表 → 认到对得上的行 → 打开 `见` 指向的知识块。**禁止通读**。
> 详细方法论：`../../internal-network/knowledge/`（域侦察 / Kerberos / 委派-ACL-ADCS / 凭据-中继-投毒 / 横向 / 隧道 / 后渗透 / 持久化 / 基础设施 / 工具投递）。
> 云上内网（元数据、AK/SK、K8s）见 `战法索引-04-云与内网.md` 与 `../../cloud-infra/knowledge/`。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| `systeminfo` 显示 Domain ≠ WORKGROUP；`ipconfig /all` 的 DNS 指向内网 IP | 先定位域控：`nltest /dclist:<domain>`、`nslookup -type=SRV _ldap._tcp.dc._msdcs.<domain>` 见 `../../internal-network/knowledge/internal-01-域侦察与决策树.md` | 能列出域控主机名/IP，SRV 查询命中 | 只是主机名带域名；DNS 走公网解析 |
| 88/389/636/445 内网可达，`netexec smb` 回 `signing: False` | 记录 SMB 中继候选（Responder + ntlmrelayx），同时找可触发认证的服务（打印机/DFS/共享） 见 `../../internal-network/knowledge/internal-04-凭据-中继-投毒.md` | 中继成功拿到目标主机管理员或域用户会话 | 目标强制 SMB 签名；中继源与目标同机 |
| 有低权限域用户，LDAP 可查 | BloodHound（`bloodhound-python -c All`）+ `ldeep` 列 ACL/委派/SPN/会话 见 `../../internal-network/knowledge/internal-01`/`internal-03` | 图里出现通向 Domain Admins 的可利用边（GenericAll/WriteDACL/委派） | 只有普通 Read 边；路径依赖已修补漏洞 |
| 有域用户凭据，账号可查 SPN | Kerberoasting：`impacket-GetUserSPNs -request` → `hashcat -m 13100` 见 `../../internal-network/knowledge/internal-02-Kerberos与票据攻击.md` | 破出服务账号明文，且该账号能登关键主机 | 服务账号是 gMSA；密码为随机长串；目标不落 SPN |
| 存在"无需预认证"的账户 | AS-REP Roasting：`impacket-GetNPUsers -no-pass` → `hashcat -m 18200` 见 `../../internal-network/knowledge/internal-02` | 破出明文并可登录 | 账户已启用预认证 |
| BloodHound 标出 Unconstrained/Constrained/RBCD 委派 | 委派攻击 S4U2Self/S4U2Proxy；RBCD 需可写目标 `msDS-AllowedToActOnBehalfOfOtherIdentity` 见 `../../internal-network/knowledge/internal-03-委派-ACL-ADCS.md` | 以任意用户（含域管）身份拿到目标服务票据 | 只委派到低价值服务；目标已勾"敏感账户不可委派" |
| 域内有 CA / ADCS Web Enrollment，证书模板可枚举 | `certipy find -vulnerable` → ESC1–ESC11 按模板对号 见 `../../internal-network/knowledge/internal-03` | 申请到可客户端认证的证书，PKINIT 拿到域管 | 模板要求审批/已加固；证书仅低权限用途 |
| 当前用户对某对象有 GenericAll/WriteDACL/GenericWrite/ForceChangePassword | ACL 滥用：改密码、加组、写 SPN、写脚本路径 见 `../../internal-network/knowledge/internal-03` | 当前用户进高权限组，或拿到目标账号哈希 | 权限只读；对象受 AdminSDHolder 保护 |
| 存在父子域/多林信任 | 子域控 + ExtraSid（Golden Ticket）/SID History 跨林 见 `../../internal-network/knowledge/internal-03` | 以父域管理员身份访问父域资源 | SID 过滤已开；单向信任方向不对 |
| 捕获到 NetNTLMv2，且能触发目标发起认证 | `ntlmrelayx` 中继到 SMB/LDAP/ADCS；ADCS 中继拿域控 见 `../../internal-network/knowledge/internal-04` | 拿到目标机器管理员或域控权限 | 目标强制签名（SMB/LDAP signing、EPA） |
| 内网有 DHCPv6，未禁 mitm6 条件 | `mitm6` 接管 DNS + 中继 LDAP 写权限 → 创建机器账户 → RBCD 打域控 见 `../../internal-network/knowledge/internal-04` | 域控被 RBCD 拿下 | 环境禁用 DHCPv6；已部署防护 |
| 已有域管/复制权限 | DCSync：`impacket-secretsdump -just-dc` 见 `../../internal-network/knowledge/internal-04` | 拿到 krbtgt/域管哈希 | 只有复制权限不足；目标已轮换 krbtgt |
| 已拿 krbtgt 或 NT hash | Golden/Silver Ticket、Skeleton Key、AdminSDHolder、DSRM 见 `../../internal-network/knowledge/internal-08-持久化与痕迹.md` | 重启或改密后仍能回到域内 | 票据时间/域功能级别限制；krbtgt 已双轮换 |
| 有本地管理员 hash，目标开放 445/135 | PTH：`impacket-psexec/wmiexec/smbexec`、`netexec -H` 见 `../../internal-network/knowledge/internal-05-横向移动.md` | 拿到目标主机 SYSTEM/管理员 | 目标禁用 NTLM；开启 LSA 保护/Credential Guard |
| 已控制一台主机，要打另一网段但不可直达 | 隧道：`chisel`/`frp`/`ssh -D` + proxychains、端口转发 见 `../../internal-network/knowledge/internal-06-隧道与多层网络.md` | 能稳定访问目标网段服务并复用凭据 | 路由不可达/出网被限；只做单跳未验证回程 |
| 拿到 Linux/Windows shell，要提权与收凭据 | 信息收集 → 提权（sudo/SUID/Capabilities；UAC/服务/令牌）→ 凭据提取 见 `../../internal-network/knowledge/internal-07-后渗透与提权.md` | 拿到高权限并发现可复用凭据 | 提权失败但有线索（记假点，别当成功） |
| 内网有 Exchange/OWA | 按版本对 ProxyShell/ProxyLogon 等 CVE → webshell/邮箱导出 见 `../../internal-network/knowledge/internal-09-内网基础设施打法.md` | 拿到 webshell 或邮箱数据 | 补丁已打；前置 WAF 拦截 |
| 内网有 SCCM 站点/管理点 | NAA 凭据提取、任务序列、站点数据库 见 `../../internal-network/knowledge/internal-09` | 拿到域管或批量主机控制 | 只读角色；SCCM 已启 HTTPS/强化 |
| 内网有国产 OA（致远/泛微/用友/蓝凌/通达/万户/金蝶…） | 按版本对已知未授权/RCE；先确认可达路径（内网/隧道） 见 `../../internal-network/knowledge/internal-09` | webshell 或数据库权限 | 已打补丁；仅内网可达需先隧道 |
| 内网数据库端口（1433/3306/5432/6379/27017）可达 | 弱口令/未授权 → 命令执行或数据访问 见 `../../internal-network/knowledge/internal-09` | 拿到库权限或主机命令执行 | 只开白名单；认证已加固 |
| 目标不能出网，需要投递工具 | 上传 `fscan`/`frp`/`chisel`/`linpeas`，走内存或白名单路径 见 `../../internal-network/knowledge/internal-10-工具投递与规避.md` | 工具在目标可执行并回连 | 被杀软拦截（记否定证据，换路径） |
