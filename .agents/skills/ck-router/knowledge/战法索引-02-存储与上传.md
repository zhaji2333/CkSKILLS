# 战法索引 02 · 存储与上传

> 详细方法论：`../../web-file-path/knowledge/`、`../../cloud-infra/knowledge/`、`../../web-ssrf-render/knowledge/`。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| 对象存储 path-style；有公开桶/README | 匿名 `GET /<bucket>/?list-type=2` 列桶；读 README 找"内部桶名"再列 见 `../../cloud-infra/knowledge/对象存储与云元数据实战.md` | 列出内部桶并读到 flag/凭据 | 只列公开桶；内部桶 403 |
| 对象存储先申 STS；key 是文件 md5；assumerole 的 `filename`/`Action` 进 Policy | 凭证字段填 `*`/空/`/`；Policy 里 filename/Action 通配；List/Delete 403 别停 见 `../../web-file-path/knowledge/file-upload-test.md` | 读到他人对象/列出他人 key | `*` 只到废桶；对探测 key 再盖 403 |
| 带签 URL 的 SignedHeaders 没有 `host` | 域名换成同账号另一个桶，加 `?uploads` 分片列举 见 `../../web-file-path/knowledge/file-upload-test.md` | 列到/读到别的桶 | 签名罩住 Host；换域 403 |
| 分享详情 JSON 一边要提取码，一边 auth 对象放明文 `pass_word` | 不登录抄明文提取码再打下文件 见 `../../web-file-path/knowledge/file-upload-test.md` | 下到密码分享正文 | `pass_word` 是哈希；空密已能出文件 |
| 上传只看扩展名/只拦 `.php`；允许 `.htaccess`/`.user.ini`/短标签 | 传 `.htaccess` AddType 把 `.jpg` 当 PHP；或 `<?` 短标签+动态函数 见 `../../web-file-path/knowledge/file-handling-03-三、文件上传绕过技术.md` | 上传后访问执行命令读 flag | 解析器不认该配置；上传目录不可执行 |
| 上传有二次渲染/图片处理/Office/PDF 预览 | ImageMagick delegate、FFmpeg、LibreOffice 宏、压缩包解压 见 `../../web-file-path/knowledge/file-handling-05-五、文件处理引擎攻击.md` | 命令执行/任意读 | 只缩略不解析；沙箱隔离 |
| 预览/下载接口吃 `file=`/`path=`/`filename=` | 绝对路径直读；`../` 被拦就试编码/绝对路径/二次解码 见 `../../web-file-path/knowledge/path-traversal-lfi-test.md` | 读到 `/etc/passwd`、应用配置/密钥文件 | 有白名单且不可绕 |
| 导入功能收 XML/SOAP/CSV/YAML | XXE 读文件；CSV 公式；YAML 反序列化 见 `../../web-deser-xxe/knowledge/deserialization-xxe-03-三、XXE-专项.md` | 回显文件内容/命令执行 | 解析器禁外部实体 |
| 压缩包上传/解压 | Zip Slip 路径穿越写文件；软链/绝对路径 见 `../../web-file-path/knowledge/file-handling-03-三、文件上传绕过技术.md` | 写到 web 目录 getshell | 解压前强校验路径 |
| 备份/日志/配置文件在 web 目录 | `/backup/`、`/db/*.db`、`*.zip`、`*.bak`、`/.git/` 目录爆破+常见名 见 `../../web-recon/knowledge/insecure-scm-test.md` | 下到 SQLite/源码/凭据 | 403 且无等价路径 |
| LFI 已确认但读不到目标 | 日志包含（UA 投毒）+ include；php://filter 读源码找 flag 位置 见 `../../web-file-path/knowledge/path-traversal-lfi-test.md` | RCE 或读到 flag | 目标目录无写权限 |
| 站点图/静态资源在对象存储桶，`?policy` 全 Allow | 无密钥 LIST；再 PUT 探测文件到官方同前缀（不盖官方对象）见 `../../web-file-path/knowledge/file-upload-test.md` | 匿名 PUT 并 GET 回探测文件 | 只能列不能写；前缀 PUT 403 |
