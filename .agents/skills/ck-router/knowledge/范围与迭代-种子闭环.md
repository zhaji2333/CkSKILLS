# 范围与迭代（种子闭环 · 深挖优先 · 续挖）

> 所属：全局作业节奏。摘要规则见 `../../../../rules/60-scope-iteration.md`。
> 本文是"怎么把一轮挖洞排满、不空转、不丢历史"的完整口径。

## 一、先判模式（当次指令优先）

| 输入 | 模式 | 行为 |
|---|---|---|
| 模糊目标（只给品牌/集团名，无 URL 清单） | **自由跳** | 种子尽能力多备 → 落盘队列 → 一种子闭环（搜一个→清洗→挖完→换下一个） |
| 固定站 / 固定 URL / 文档 / URL 清单 | **锁面** | 不主动出圈测绘；资产簇内多 host、业务流子域、同 host 多 path 都要挖 |

## 二、锁面口径（防"锁太死"）

- **锁的是**：别未进站就测绘全集团、别跳到无关旁系域名。
- **不锁**：入口 host；页面/JS/配置里的业务 host；业务流自然跳到的子域/网关；同资产簇多 host；同 host 多 path。
- **顺序**：用户标"重要/优先"的先打；"一、二、三"不等于必须从上往下。
- **同皮**：同模板只留 2–3 个代表；登录壳同皮则登录表单不重复磨，只比"有没有新的重置/改绑/换票 path"。代表站做过的交付，sibling 一眼差分。
- **禁误解**：锁面 ≠ 只测文档那一条 path；≠ 子域一变就停。

## 三、自由跳：种子与一种子闭环

### 3.1 种子尽能力多备（硬）

- 业务名/产品/子品牌（支付/金融/云/链/出行/数字科技/国际/内部线…）、全资 1–4 级、根域、备案、SRC 对外名——能列多少列多少，**不设上限**；
- 落盘：`hunts/<目标>/SEEDS.md`（表格：种子 | 类型 P0/P1/P2 | 状态 pending/doing/done/cold | 备注）；
- 禁止：队列只有用户原词；写死固定条数；只口头列不落盘；续挖装看不见旧队列。

### 3.2 一种子闭环（硬，无例外）

```
取一个种子 S
 → 只搜这一个 S（测绘平台结果可翻页，仍是这一种子）
 → 去重 → 去废（无效/广告/停放页）→ 去非存活 → 归属过滤
 → 剩余活面全部挖完（每站过"本轮完成"标准，或记废/同皮代表已做/已覆盖）
 → 本种子标 done → 才允许搜下一个种子
```

**禁止**：多种子连搜/一次搜完再回头挖；本种子还剩未挖活面就开下一种子；把"分批"（本种子翻页）误解成"多种子连搜"。

**"挖完"的边界**：清洗后每个该挖的 host 都过了本轮矩阵（清单 + 类型矩阵 + 有差分面的四件套 + 认证口勾项；有会话加对象图/换 id），或已记废/非存活/同皮代表已做。**不是**刨完每个历史 path，也不是给 80 个空壳各喷一轮。

### 3.3 优质根域回灌（硬）

一确认优质面，立刻把"业务簇根域/品牌根域"（不是叶子 host）写入队列 pending 并注来源；但**本种子剩余活面挖完前不去搜回灌根域**。

## 四、队列与回合闸（防空转收工）

- 队列状态机：`pending → doing → （只搜这一个）→ 清洗/挖完 → done / cold`；
- 本种子 done 的同一轮内立刻取下一个 pending，禁止"done 后停住等用户说继续"；
- **回合结束前必须读队列**：有 pending 不许以"要不要继续/下一步您看"收尾；
- 续挖：读队列 + 已覆盖记录 + 报告目录，从 pending 或未完成项开干；禁止用空队列覆盖历史；可增量补齐层级与新业务名；
- 全 done：随机再搜新业务名，或回扫旧种子只捞新增 host；禁止空等。

## 五、空转判定（自触发纠偏）

命中即"换本种子下一条活 host（或记废）"，不要在 403 壳/无账密健康页/已覆盖登录表单壳/已报过的点上重复堆探测：

| 信号 | 动作 |
|---|---|
| 报告长时间不增，只见 403/health/重复 path | 换本种子下一条活 host |
| 瘦壳（403、无业务 JS、同闸）15–20 分钟无苗头 | 杀这条线，换下一条 |
| 肥面（JS 多、后台、业务 JSON）还在抽 chunk/还原签名/建对象图 | **不算空转**，继续 |
| 把"扫到资产/探活数"当进度 | 假进度 |
| 未建接口清单就盲扫、类型只测两三种 | 假进度/偏科 |

**不算进度**：测绘条数、探活计数、假中间件、纯文件通道、已落盘那份再确认一遍、CORS、纯登录码上把四件套勾一遍、每个 path 喷 `'` 但无差分。
**算进度**：说清这摊、接口清单（或合法降级）、回包线索进队列、业务 JSON 全类型矩阵、有差分面的四件套、认证口有入口已勾/无入口 N/A、有会话对象图、正式报告落盘。

## 六、深挖优先闸（只纠节奏，不砍能力）

> 口令：**一种子搜 → 清洗 → 挖完剩余活面 → 才换种**；本种子内先清单后矩阵，先矩阵后换站；优质只回灌不改道；限流只挖池。

| 闸 | 规则 |
|---|---|
| A | 本种子清洗后仍有未挖活 host，或近 15 分钟主要在扩面/探活且清单未建 → **禁止搜新种子**，只挖本种子剩余 |
| B | 当前 host 未达"本轮完成"，禁止用"再搜一批/先搜完种子"充进度；先清单→矩阵→落盘/证伪，再换下一条 |
| C | 优质词/根域出现 → 立刻落盘 pending，**不打断当前站**；本种子剩余挖完再搜 |
| D | 测绘配额尽/限流 → 停搜，只挖已入库剩余；禁止空撞 |
| E | 多线程禁"双测绘工厂"：至少一个线程在建清单/挖站 |

**不砍**：种子多备、全类型矩阵、注入/SSRF/XSS/RCE 深度、JS 跟 host、漏洞链、新攻击面、工具切线、用户当次加码。规则与打穿冲突时，以打穿与证据为准，事后记一笔为何破闸。
