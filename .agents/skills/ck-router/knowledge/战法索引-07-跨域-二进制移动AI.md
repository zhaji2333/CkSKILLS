# 战法索引 07 · 跨域（二进制 / 移动 / AI）

> 跨域题先走对应技能包 SKILL.md（`binary-re` / `mobile-app` / `ai-agent`），本表只给首枪。

## 二进制 / 固件 / 内存破坏

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| TCP 行协议服务，响应含未初始化内存/超长回显 | 触发 BUILD/DUMP/REVEAL/LIST 等"导出"指令；填满缓冲区后读相邻内存 见 `../../binary-re/knowledge/二进制与固件逆向实战.md` | 回显中出现凭据/密钥/敏感字符串 | 只回固定占位符 |
| 服务按"请求长度"回显数据（heartbeat 类） | 声明长度 > 实际载荷，越界读内存（偏 0x1000 处常预置 flag）见 `../../binary-re/knowledge/二进制与固件逆向实战.md` | 越界字节中出现 flag | 长度被上限截断 |
| 写入/拷贝类指令带偏移参数 | 负偏移/超长偏移覆写 guard/secret 判定变量，再 REVEAL 见 `../../binary-re/knowledge/二进制与固件逆向实战.md` | REVEAL 吐出 flag | 有边界检查 |
| 固件/ELF stripped，有 XOR 常量表/状态机 | 找 rodata 的 XOR 表/口令常量；还原状态转移；FNV/PJW/djb2 派生 keystream 见 `../../binary-re/knowledge/二进制与固件逆向实战.md` | 解出授权凭据/密钥（可验证的完整值） | 解出的是 decoy/占位值 |
| Go/静态编译 stripped | 用 pclntab 恢复符号（debug/gosym 或手写解析）找 reveal/keySchedule 见 `../../binary-re/knowledge/二进制与固件逆向实战.md` | 拿到授权码/算法参数 | 符号被抹除且无字符串线索 |
| 授权校验通过后才输出设备凭证 | 逆向确认主路径（正确 key/口令/环境），让校验走通后读取授权文件/输出凭据 见 `../../binary-re/knowledge/二进制与固件逆向实战.md` | 拿到真实授权凭证/命令输出 | 只拿到回退路径的演示凭据 |

## 移动 / Android / 小程序

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| APK 要快筛密钥/签名/隐藏接口 | ASC 先 `getmanifest`/`findrefs`，再 JADX 精读 见 `../../mobile-app/knowledge/asc-fast-hunt-04-三、标准工作流-快筛循环.md`（无则 `../../mobile-app/knowledge/android-security-audit-05-🔴-一、密钥追踪-→-未授权接口专项-最高优先级.md`） | 提取 appKey/appSecret/签名算法 | 占位符/已吊销 |
| 硬编码密钥 → 未授权接口 | 用提取的 key 重算签名直接调接口 见 `../../mobile-app/knowledge/android-security-audit-05-🔴-一、密钥追踪-→-未授权接口专项-最高优先级.md` | 接口返回数据/他人数据 | 签名绑定设备 |
| 导出组件/Intent/WebView/Provider | 外部显式 Intent 拉起导出组件；WebView `addJavascriptInterface` 打 JS 桥 见 `../../mobile-app/knowledge/android-security-audit-06-二、静态分析.md` | 组件内敏感功能被外部触发 | 组件未导出 |
| 加固壳 | Frida dump/apktool 后再审计 见 `../../mobile-app/knowledge/apk-reversing-01-标准产物-交付标准.md` | 还原真实 dex | 壳未脱净 |
| 小程序/云开发 | 反编译 wxapkg → 提取 appid/secret → 云函数未授权/云开发匿名登录 见 `../../mobile-app/knowledge/miniprogram-security-01-快速开始-5-分钟出第一个接口-凭证.md` | 未授权接口/他人数据 | 云函数鉴权严格 |

## AI / Agent / 沙箱

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| Chatbot/LLM 应用有用户输入进提示词 | 提示词注入/越狱/System Prompt 泄露 见 `../../ai-agent/knowledge/ai-llm-agent-security-04-三、提示词注入-Prompt-Injection-——-LLM01.md` | 系统提示泄露/越权工具调用 | 模型拒答且无侧信道 |
| RAG/知识库可写 | 投毒检索内容诱导输出 见 `../../ai-agent/knowledge/ai-llm-agent-security-07-六、RAG-检索污染与向量库弱点-——-LLM08-LLM04.md` | 输出被植入内容/泄露 | 只读知识库 |
| AI 平台有对话口 + 工具（bash/code_exec） | 让 Agent 执行命令；看工具列表/SSE toolName 见 `../../ai-agent/knowledge/agent-tool-exec-test.md` | 命令 stdout | 只口头说执行；沙箱 uid 不算 |
| Agent 平台 API 可直打（F12 抓 exec/files/tool） | 换 sandbox_id/session_id/user_id 测跨租户 见 `../../ai-agent/knowledge/agent-execution-channel-hijack-03-三、HTTP-跨租户-必须三态-+-对照.md` | 他人会话数据/执行 | 接口有租户校验 |
| 在线代码执行沙箱（Python/JS） | `__subclasses__`/`__globals__`/`process.mainModule`/vm 逃逸 见 `../../ai-agent/knowledge/agent-sandbox-takeover-02-二、进站决策树.md` | 命令执行读 flag | 真沙箱（无逃逸面） |
| 产品实例（按指纹对号） | Langflow `validate/code` exec；ComfyUI `/api/userdata` 写配置+重启+恶意节点；Dify/Next.js RSC；Gradio `component_server` 文件读；HugeGraph/Gremlin 改线程名；1Panel EntranceCode；OFBiz EntitySQL；GeoServer GetPropertyValue 见 `../../ai-agent/knowledge/AI平台漏洞实战.md` 与 `../../cloud-infra/knowledge/中间件与产品CVE实战.md` | 未授权命令执行/文件读 | 版本已修补 |
