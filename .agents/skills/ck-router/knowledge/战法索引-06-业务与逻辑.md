# 战法索引 06 · 业务与逻辑

> 详细方法论：`../../web-logic-race/knowledge/`（v1 business-logic-race + 实战 logic/race）。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| 秒杀/限量商品 + 优惠券 | 下单只传 `product_id`，服务端不校验应付金额；或改价参/数量为负/小数 见 `../../web-logic-race/knowledge/business-logic-race-03-三、业务逻辑漏洞攻击套路.md` | 以低于应付价下单成功/直接出 flag | 服务端校验金额且回滚 |
| 领券/兑换/积分可重复 | 并发领券（同一账号多请求同时发出）；券码/订单号重放 见 `../../web-logic-race/knowledge/race-condition-test.md` | 领到多张/多份权益 | 幂等键严格 |
| 支付/下单回调 | 伪造回调（无签名/弱签名/金额未校验）；订单状态跳变 见 `../../web-logic-race/knowledge/logic-test.md` | 未支付变已支付/金额改小 | 强签名+金额核对 |
| 退款/提现/余额 | 退款金额可改；负数提现；并发退款 见 `../../web-logic-race/knowledge/race-condition-test.md` | 多退/余额增加 | 服务端流水校验 |
| 审批/工单/权限流 | 越级审批、改状态参、跳过节点；审批人 id 可换 见 `../../web-logic-race/knowledge/logic-test.md` | 以他人身份审批/越权通过 | 状态机服务端校验 |
| 库存/兑换库存 | 并发扣库存为负；超卖 见 `../../web-logic-race/knowledge/race-condition-test.md` | 超卖/多兑换 | 事务+锁 |
| 数量/价格/折扣字段 | 负数、小数、超大数、0 元、精度截断；优惠叠加 见 `../../web-logic-race/knowledge/business-logic-race-01-一、业务逻辑建模-先理解再测试.md` | 0 元/低价成交 | 前后端双校验 |
| 试用/会员/订阅 | 改到期时间/改套餐 id/并行领多次试用 见 `../../web-logic-race/knowledge/logic-test.md` | 白嫖/权益叠加 | 服务端权益唯一 |
| 邀请/拉新/助力 | 自邀、批量注册、改邀请人 id 见 `../../web-logic-race/knowledge/logic-test.md` | 奖励到账 | 风控限制 |
| 分页/导出/批量接口 | 分页大小改大/导出不过滤/批量 id 换他人 见 `../../web-auth-access/knowledge/auth-access-control-05-五、访问控制与越权.md` | 导出他人数据 | 服务端权限过滤 |
| 竞态通用判据 | 同一资源两请求并发，结果违反不变量（余额、库存、唯一性）见 `../../web-logic-race/knowledge/business-logic-race-04-四、并发与竞态专项.md` | 不变量被破坏 | 只有一个请求成功且幂等 |
