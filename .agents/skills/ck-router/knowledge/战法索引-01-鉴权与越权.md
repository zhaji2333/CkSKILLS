# 战法索引 01 · 鉴权与越权

> 用法：进站先扫本表 → 认到对得上的行 → 打开 `见` 指向的知识块。**禁止通读**。
> 详细方法论：`../../web-auth-access/knowledge/`（v1 auth-access-control + 实战 authbypass/idor/oauth-jwt）。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|---|---|---|---|
| 登录页吃 `?token=`；二维码登录回包有 token | 不登录抄 token；把带 token 的登录 URL 直接打开（等于确认扫码）见 `../../web-auth-access/knowledge/authbypass-test.md` | 未登录端变成对方号 | token 过期；只出码不绑会话 |
| 未登录首页/运营配置 JSON 的跳转 URL 带能当会话的 token | 不登录抄出来当 `Authorization`/`Token` 打 `/me`、`/info` 见 `../../web-auth-access/knowledge/authbypass-test.md` | `/me` 是别人的手机/角色 | 只是占位串；配置只出文案 |
| 详情 id 是密文；JS 有 `modulus`/JSEncrypt/`security.js`；落地页写死公钥+演示 userid | 回包找明文序号；用公钥加密相邻数字换进去；演示号则加密写死的 userid 打工单列表再换邻号 见 `../../web-auth-access/knowledge/idor-test.md` | 出他人地址/手机/姓名 | 会话绑死只回自己的；加密后仍是公开 FAQ |
| 列表按 `appId`/`tenantId` 过滤；附件是带 sign 的下载 URL | 租户字段试 `0`/`-1`/空；附件 URL 只改租户 见 `../../web-auth-access/knowledge/idor-test.md` | 列表出现他租户数据，附件真下到证照 | 仍只回自己的；换租户 403 |
| 管理后台 SPA 拦截器把自定义头（`User-Id`/`employeeId`）当身份；未登录名单口只出数字号 | 名单抄数字号，把头换成这个号打当前人信息口 见 `../../web-auth-access/knowledge/idor-test.md` | 出他人姓名+11 位手机 | 头过了仍空；名单已出手机（另一条） |
| 匿名 CSRF/临时 token 口；业务详情只验这个头不验登录 | 不登录拿临时 token 头打详情换数字 id 见 `../../web-auth-access/knowledge/idor-test.md` | 未上架/测试/内部会话正文 | 只有公开广场；token 过了仍空 |
| BaaS 匿名 session；列表口不验管理员；未登录业务口 JSON 报缺参 | 用匿名 session 打管理列表；缺参不一定是登录闸，带可解析业务 id 再打 见 `../../web-auth-access/knowledge/authbypass-test.md` | 列表出现全部数据/管理员数据 | 只有公开数据；匿名 session 无权限 |
| 未登录发签口给 IM/RTC/体验 userSig；identifier 跟请求走或票里没 userId | 不登录拿签登 IM 拉他人会话/群；v2 403 改 v3 见 `../../web-auth-access/knowledge/authbypass-test.md` | 拉到他人会话/群成员/明文手机 | 只能登游客 null；换 UserID 失败 |
| H5/落地页写死产品号；发签口不登录给共享产品号 JWT | 不登录 POST 发签，带票打 JS 没写出来的 list 见 `../../web-auth-access/knowledge/authbypass-test.md` | list total 海量且带他人原图/证件 | 票只能建空任务 |
| 企业 IM 发签口回包 `nonceStr` 以 `MIIE`/`BEGIN` 开头 | 把 nonce 当 PKCS8 私钥 load，不要当随机串丢掉 见 `../../web-auth-access/knowledge/authbypass-test.md` | 能 load 成 RSA 私钥 | 只是短随机串；假 corpId 业务错 |
| 登录只校验用户名（无密码） | 任意用户名登录 → 直接打购买/导出/管理接口 见 `../../web-auth-access/knowledge/authbypass-test.md` | 业务动作以他人身份成功或出 flag | 服务端另有 session 校验 |
| 找回密码流程有身份 id + 验码/旧密字段 | 改 id 为他人；验码可爆破/回显/复用 见 `../../web-auth-access/knowledge/authbypass-test.md` | 能重置他人密码 | 验码强绑定；有频率限制且不可绕 |
| 后台登录页只跳 SSO，但后端仍有账密登录 API | 直接打 `/api/login` 账密口（可能未接 SSO）见 `../../web-auth-access/knowledge/authbypass-test.md` | 账密登录成功拿到后台 | 后端口已下线/统一 SSO |
| 验证码 4 位/图片码；同 session 可复用 | 同一 session 连用数十次爆破/绕过 见 `../../web-auth-access/knowledge/auth-access-control-03-三、验证码安全专项.md` | 登录成功/爆出账号 | 验证码一次性且强绑定 |
| JWT：HS256 + `kid` 指向文件；`/keys/` 可读或可推测文件名 | `kid` 路径穿越到可读文件当 HMAC 密钥，伪造 admin 声明 见 `../../web-auth-access/knowledge/oauth-jwt-test.md` | 伪造 admin token 通过验签 | 验签严格 + 密钥随机不可读 |
| JWT：允许 `alg=none`/算法混淆/`jku` 可控 | 换算法/自签 JWKS 上传到站内受信路径 见 `../../web-auth-access/knowledge/oauth-jwt-test.md` | 任意 claim 通过 | 只认固定 alg/固定 jku 白名单 |
| 开放平台/合作方入驻查询口未登录，参是执照号/手机/名字 | 不登录查，空结果时 JSON 格式参常仍出数 见 `../../web-auth-access/knowledge/idor-test.md` | 出他人执照/手机/合作方数据 | 只出公开公示信息 |
| 电子发票/合同/凭证下载 path 把流水号当文件名 | 不登录 `GET /download/{serialNo}.pdf`，假号对照 见 `../../web-file-path/knowledge/file-upload-test.md` | 下到他人发票原件 | 下载也要登录/极验；假号同占位票 |
| 管理台前端只跳 SSO；同产品另有独立身份子域同一套账号 API | 直接打身份子域账号 API（不带 Cookie）见 `../../web-auth-access/knowledge/authbypass-test.md` | 未登录改密/查账号成功 | 子域也要会话 |
