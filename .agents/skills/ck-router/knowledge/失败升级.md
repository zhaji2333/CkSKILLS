# 失败升级（Level 1–7）

> 同一手法反复不中、且没有新证据/新解释 → 换层；换层看边际收益，不设固定次数。换层时写明已试维度与否定证据。
> 下"无此漏洞"结论前把适用维度过一遍，别凑层数。

| Level | 维度 | 例子 |
|---|---|---|
| L1 | 编码 | URL/HTML/Unicode/UTF-16/双重编码/八进制转义 |
| L2 | 变形 | 大小写/分隔符/空白/等价函数/截断/双写 |
| L3 | 逻辑 | 顺序/参数污染/类型混淆/边界值/多值/重复键 |
| L4 | 协议 | 分块/压缩/头部/Host/HTTP2/方法/路径规范化差异 |
| L5 | 换入口 | 同业务另一接口/另一 Host/移动端 API/旧版本/子域 |
| L6 | 组合 | 低危拼接（信息泄露→IDOR→RCE）/链式利用 |
| L7 | 时间 | 竞态/重放/延时/缓存/定时任务 |

## 记录模板（写进线索板 §4 或报告）

```
入口: <URL/参数>
已试: L1 编码(UTF-16 绕过 WAF) / L2 双写 / L3 参数污染
结果: 均 403/空
否定证据: 回包固定 WAF 页、无业务差异
结论: 到 Lx；下一步 <换入口/换层/放弃>
```

## 停止条件

- 拿到 flag/证明 → 停；
- 环境不可达（VPN/平台）→ 停并报告；
- 平台返回任务结束/资源耗尽 → 停并报告；
- 持续无新增证据 → 考虑换目标或换题（不设固定轮次，看边际收益）。
