# 进站决策（30 秒分诊）

> 每接一个新目标/新题，先走这张表，再决定加载哪个技能包与读哪张战法索引。

## 0. 先看物料

| 你拿到了什么 | 下一步 |
|---|---|
| 只有 IP:PORT / 域名 | Web/服务类：先指纹（server/title/框架/端口），走 §2 |
| 源码 / 反编译产物 | `source-audit`；再按语言危险函数表过一遍 |
| 二进制 / 固件 / APK | `binary-re` / `mobile-app`；先 `file`/`checksec`/`strings`/manifest |
| 云账号/面板/对象存储地址 | `cloud-infra`；先看未授权枚举面 |
| AI/LLM 应用/Agent 平台 | `ai-agent`；先建信任边界（谁调模型/工具/检索） |
| 题面给账号或 flag 路径 | 直接按题面找入口，别做无关测绘 |

## 1. 决定范围模式

- **锁面**：固定资产/文档/清单/已知范围 → 清单内全打，同皮去重（2–3 代表）。
- **自由跳**：只给品牌/集团名 → 种子落盘 → 一种子闭环。

## 2. 指纹 → 首枪（Web/服务）

1. `nmap -sT -p- --min-rate 2000 <ip>`：全端口，别只看 80/443。
2. 每个 HTTP 端口：`curl -i` 看 `Server`/`X-Powered-By`/`Set-Cookie`/标题/跳转。
3. 按指纹加载包：
   - 登录/注册/会话 → `web-auth-access`
   - 搜索/排序/详情参数 → `web-injection`
   - 上传/预览/导入/下载 → `web-file-path`
   - URL 抓取/转换/渲染 → `web-ssrf-render`
   - API/GraphQL/WS/网关 → `web-api-protocol`
   - 支付/券/审批 → `web-logic-race`
   - XML/序列化 → `web-deser-xxe`
   - 其余/不明确 → `ck-router` 的战法索引
4. 读对应 `战法索引-0X` 的**前 5 行**当首枪；每枪记录到线索板。

## 3. 30 秒内必须产出的三样

- 一份入口清单（端口→URL→指纹）；
- 一个"最像题眼"的入口（题面带 flag 路径/账号时优先按题面）；
- 线索板 §0 当前焦点（下一轮第一件事）。

## 4. 何时升级 / 停止

- 同一入口反复无结果、无新信息 → 换层（`rules/30`，不设固定枪数）；
- 拿到 flag/证明 → 立刻提交/记录，停止扩展；
- 环境不可达/平台返回任务结束 → 停止并报告，不空转。
