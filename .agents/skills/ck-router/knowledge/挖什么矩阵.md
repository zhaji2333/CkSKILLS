# 挖什么矩阵（价值导向 · 力气分配 · 类型扫全）

> 所属：全局选择与优先级。规则摘要见 `../../../../rules/15-hunting-mindset.md` 与 `../../../../rules/70-routing.md`。
> 目标：力气先砸更容易出高危/严重的点；类型与参数都要扫全，不偏科。

## 一、什么叫"真价值"

能到高危/严重那一档：**跨租户/跨用户读或写、未登录出业务敏感、低权到平台/官方管理员、注入出他主体、完整链（跨用户写、进号、命令执行）**。

**"管理员"语义（易误读）**：
- 盯的是**平台/官方级管理员**能否拿到，以及提权链；
- 不是"当前是租户管理员所以能看的都不算洞"；
- 租户管理员是**跳板视角**：用本租户基线（如会话里 total=2）对比注入/越权后是否变成海量/他租户数据。

## 二、力气怎么分（先打更容易高危/严重的）

| 先打 | 说明 |
|---|---|
| 未登录出他人/他主体 | 不登录出名单/详情/附件；通了再换 id（不限字段名）；文件通道开了转业务，别停在"能传能下" |
| 认证接管 | 发会话/重置/改绑/换票；**进号或改密才算打穿** |
| 换 id（不限字段名） | 无会话：未授权通了再换；有会话：带会话换；他主体数据出现算打穿 |
| 有会话写/逻辑 | 加 `role`/改金额/改状态/跳审核/券库存并发；盯租户身份能否到平台管理员 |
| 四件套全硬 | 有条数/回显打注入；会拉网址打 SSRF；有回显/能存打 XSS；有命令/模板跟 RCE；注入要出他主体或稳定差分 |
| JS 钥匙 | 盐、硬编码 key、演示号 |

**无会话顺序**：未授权通→换 id → 认证口 → JS 钥匙 → 有差分面的四件套（含 XSS）。
**有会话顺序**：带会话换 id → 加字段/跳步/改钱 → 四件套打在已出数的业务参上（含 XSS）。

**不当主业**（有入口仍测）：只害自己的 CSRF（跨用户写成功仍要跟）、能传能下无链、登录框弱口令、CORS（不挖）。

## 三、类型矩阵（每轮目标至少过一遍）

| 类型 | 探针要求（有入口就打完；无入口写 N/A + 原因） |
|---|---|
| 未授权 | 关键读/写用 `credentials:omit`；通了再换 id |
| 越权/IDOR | 有入口打完：基线 → 邻号/回包里抄的 id/`0`/`-1`/空 → 附件导出；不为第二号停工 |
| 注入 | 能看出条数/内容变化、或会去拉网址的口：**每个**查询/过滤/排序/关键字参数都测（基线→探针→差分）；只回"请登录"整段 N/A；**按栈选探针**（JSON/Mongo 操作符、搜索 ES/OR+total、Java HQL/SpEL、模板 SSTI、SQL `'`/布尔/延时）；被拦换位置（query/json/header/path） |
| SSRF | 全部 URL/回调/webhook/file/fetch/import/preview/proxy 参：内网/元数据/外带 |
| RCE/代码执行链 | 命令/表达式/模板/反序列化/危险上传等 Sink 跟到执行或证伪 |
| 凭证/密钥泄露 | 抄到 token/AK-SK/私钥/连接串：假值对照、认钥枪须带出身份或列表、再打不影响线上的只读例；占位/过期/失效 → N/A |
| 弱口令/默认口 | 中间件/组件裸默认口可一眼；打到真进会话；登录表单弱口令不当必做；JS/页里的演示号、测试租户当钥匙 |
| 敏感路径 | Swagger/Actuator/debug/heapdump/env 等；有 key 接着挖 |
| XSS | 反射（回显打标签/事件）+ 存储（可写点再读回）；结合是否未登录可读 |
| 上传 | 类型绕过、路径、可执行/SSRF 链；别停在能传能下 |
| 穿越 | fileKey/path/filename |
| CSRF/鉴权参数 | 无 token/坏 token + Cookie 属性；写操作是否成功 |
| 提权/逻辑 | 写接口加 `role`/`isAdmin`/`amount`/`status`/`vip`（只改能改回的）；多步流程跳步；钱/券/库存改小改负改小数；领取/审核见就并发一枪 |
| 认证/任意登录/接管 | 清单有发会话/重置/改绑/换票/2FA → 按认证链勾完；用户名密码框不当四件套 |
| CORS | **N/A · 不挖** |
| 其它现场面 | 矩阵未点名的照样测；认证口走上一行 |

## 四、接口与参数：禁止漏字段

1. 打开真实页面 → 抓**完整**请求（query + body）。
2. 列出全部 filter/id 字段，**短枚举字段也要测**（如 `vote`、`answerType`、`status`）。
3. 有差分面的口，每个过滤参最低矩阵：
   - 正常值 / 空 / 非法值；
   - 按栈选探针（SQL `'`/布尔；JSON 操作符；搜索 ES/OR+total；Java HQL/SpEL；模板 SSTI）；
   - 延时（按库型）；
   - WAF 编码（`%0a`/`%0d`/双写/注释/大小写混用）**并换位置**（query/json/header/path）。
4. **差分是硬证据**：本租户基线 total/条数 vs payload 后 total/他主体字段。

## 五、挖到这些别停在半截

- 文件通道开了 → 立刻转业务 API / 可执行 / 路径 / SSRF 链；
- 发码接口通了 → 跟认证链：回包有没有码、码绑不绑号、重置换不换用户；
- 滑块过了/能试密 → 表单壳停，打空密、跳步、重置、改绑；
- DSN/配置只有 host 没账密 → 继续找完整凭据；有账密/AKSK → 假值对照后当钥匙用；
- 回包冒出 id/下载地址/token/内部 host → 进本站队列再打；
- 本职可读、公开静态、接口 200 有 JSON → 转跨用户/注入/提权；
- **中危落了先升链再换站**：同一对象还没走到写/跨用户/接管/可执行，先跟。

- [ ] 未授权用 omit 测过？跨租户/他用户测过（不是只测本租户可读）？
- [ ] 有会话时对象图/换 id/加字段/跳步打了？
- [ ] 上传跟到可执行/SSRF/业务越权了？发码/滑块后认证链打了？
- [ ] "管理员"是否误判成"权限内不算洞"？WAF 405 后是否换编码/换位置？
- [ ] 有无误挖 CORS？本轮是否偏科只挖未授权读？
- [ ] 注入/SSRF/XSS/RCE 是否真打过或 N/A+原因（有没有连日空窗）？
- [ ] 中危同一对象是否先升链？回包线索进队列了？
