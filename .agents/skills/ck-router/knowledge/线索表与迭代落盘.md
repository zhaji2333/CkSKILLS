# 线索表与迭代落盘（战法索引怎么维护）

> 所属：知识资产维护。索引 = `战法索引-01~07`；正文 = 各包 `knowledge/` 小块。
> 目标：把"下次还能出高危的手法"留下；索引是索引、正文是正文，不互相复制。

## 一、定位

- 索引是**快速索引**：一行一枪（认什么→打哪→怎么算成→假点），指向正文；
- 正文是**细节库**：步骤/编码/证伪/长链写进对应知识块；
- 现场与索引冲突：**听现场**；索引不是白名单，也不是上限；表上没有的照样挖。

## 二、落哪（写前先想清楚）

| 内容 | 落点 |
|---|---|
| 步骤/编码/证伪/长链 | 对应包的 `knowledge/` 小块（没有就新建按手法命名的块） |
| 一行手法或指针 | 对应 `战法索引-0X` 的一行 |
| 本次正式报告 | 任务目录 `报告/` |
| 本次 URL / 提取的 JS | 任务目录 `资产/`、`js/` |
| 单目标状态 | `hunts/<目标>/CLUEBOARD.md` |

禁止：把索引写成日记/周报/单 host 档案；在任务目录放"复盘/经验"文档；把密钥实值、完整 JS 抄进知识库。

## 三、进索引的门槛（硬）

1. **先过报告定级门槛**：拿本篇报告正文对照 `../../../../rules/40-evidence-report.md` 的定级标准，真的做成了高危/严重才算；标题写"高危"不算；一条都不中 → 当没高危，不进索引。
2. **中危只写报告**：不进索引、不拟进、不补知识块。
3. **来源**：自己挖的必须是已落报告的高危/严重；他人丢进对话的要有可对照的报告/payload 正文，只有"有个洞"不算。

## 四、三问（过门槛后再问；答不出或否定 → 不进）

1. **可迁移**：换一个站/换同形态产品，还能"认到 A、按 B 打"吗？
2. **非单点**：认的是不是只有这个 host/这条 path/某个产品字段名？换同形态产品认不到同一套 → 不进（单站备忘；报告照写）。注意：不是字段名黑名单——同形态还能认到同一套、差得出新认法，仍可进。
3. **有增量**：已有行多出来的是**新认法 / 新打法 / 新假点**吗？差不出不写；差得出且已有同类 → 只补原行，细节进正文。

**太窄**：这家特有接口名、延迟、活动号、死 path → 不进，只作单站备忘。
**无新认的通用枪**（换 id、空密、omit、列表自增、每个 path 丢 `'`）不进——那是基础动作，不靠索引记。

## 五、已有同类与假点

- 已有同类：**禁止另开一行/另起一篇**；有新差分就只补原行或原正文；"认什么"保持形态（框架/参数/业务面），产品名/完整 path/字段枚举进"打哪"或正文。
- 假点列只记**"这种形态不是洞"**；禁止写"这站没注进去/这站 401/这次超时"。
- 这次没打穿 = 这站现场不行，下一站同类手法照样打；**不因此删行/标失效**。
- 只有确认"形态从来不是洞/整个手法前提没了"才改假点或删行；拿不准就留着。

## 六、索引/正文肥了怎么办（顺序不能反）

1. **并**：同一"认什么"多行合并成一行；合并后"认什么"仍是形态，不是"A 产品或 B 产品"。
2. **分流**：一簇不是一行能说清 → 细节并进已有正文块，索引只留 1 行指针；没有对应块就新建按手法命名的块。
3. **只删**：确认形态不是洞的废假点；确认整个手法前提没了的行；误写进索引的单站备忘。
4. **禁止**：按日期/按任务拆索引；删仍可能出高危的手法行（冷门 ≠ 作废，单站没中 ≠ 手法死亡）。
5. 正文肥了：按手法/类型拆成两篇，索引指针改到新篇；禁止按月拆库、禁止索引与正文互相复制全文。

## 七、谁写、何时写

- 单线程：过了门槛+三问 → 同一轮写/补，**不等"放"**；没过就不写、不问。
- 子线程：禁止直接改索引/正文；在本站 `DONE.md` 写一行 `拟进：认…打…` / `拟补：哪一行多了啥` / `不进：原因`；主控复核后再并。
- 子线程写线索板：同样禁止直接写板；按 `rules/66-agent-teams.md` 收工交 `dig/<角色>/SYNC.md` 回灌块，Lead 合板（与 DONE.md 分工：日常回灌用 SYNC，换站拟进索引用 DONE）。
- 时机：高危报告落盘后、换站前花半分钟写"拟进/拟补/不进"；中危不拟进；写索引不挡换站。
- 五不写：没出洞的流水、测绘条数、纯登录墙过程、同皮再确认、只用一次的 path、完整 token/密钥实值。
