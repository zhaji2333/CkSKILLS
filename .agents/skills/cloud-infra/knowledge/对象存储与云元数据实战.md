# 对象存储与云元数据实战

> 来源：真实云环境授权评估沉淀（S3 兼容、Azure Blob、云函数、IMDS）。与 `../../../../rules/20-min-harm.md` 冲突时以规则为准。

## 一、对象存储（S3 兼容 / path-style）

**枚举顺序**

1. `GET /` 首页常写 bucket 规则；有公开桶时 `GET /<bucket>/?list-type=2` 列对象。
2. 读公开桶里的 `README.txt` / `index.html` / 错误页——**内部桶名常明文写在提示里**（如 "legacy data migrated to secret-data bucket, ACL pending"）。
3. 内部桶逐键读：`flag.txt`、`credentials/api-keys.json`、`credentials/db-passwords.txt`、`backups/*.yaml`。
4. 没有提示就枚举常见桶名：`backup(s)`、`private`、`internal`、`secret(s)`、`data`、`logs`、`admin`、`company-*`、`*-assets`。

**SAS / 临时凭证类**

- `/api/sas/generate` 无认证返回 account 级 SAS（`srt=sco`、`sp=rwdlac`）→ 可用列容器/读对象。
- 代理只允许读单个 blob 时，用 `blob="%2E"`（`.`）或把 container 段做成查询注入，使请求落到 container 级 `comp=list`，再列桶。

**STS 类（对象存储 → 云 API）**

- 拿到 AccessKey/Secret/Token 后：`aws s3 ls`（或 curl 签名）列桶；只读角色也要试 `s3:ListBucket` + `s3:GetObject`。
- `filename`/`Action` 进 Policy 时用 `*`/空/`/` 做通配扩展。

## 二、云元数据（IMDS）

| 云 | 路径 |
|---|---|
| AWS | `http://169.254.169.254/latest/meta-data/iam/security-credentials/` → `<role>` → AccessKeyId/SecretAccessKey/Token |
| 阿里云 | `http://100.100.100.200/latest/meta-data/`（ram/security-credentials） |
| 模拟环境 | 常见 `http://imds:8080/latest/meta-data/...`、`metadata_endpoint` 由 `/api/status`/`/debug` 泄露 |

**流程**：SSRF 入口 → 先读 `/api/status` 找 `metadata_endpoint`/内网服务名 → 打 `security-credentials/` 拿 role → 打 `security-credentials/<role>` → **SecretAccessKey/SessionToken 是可用凭据**（可直接调云 API 横向/取数） → 再考虑用凭据调云端 API 横向。

## 三、云函数 / Serverless 门户

- `GET /api/functions` 未授权列函数名 → `GET /api/functions/<name>/config` 泄露环境变量（DB 密码、flag）。
- 函数列表里常有噪声函数，逐一看 config；重点 `DATABASE_PASSWORD`、`SECRET_*`、`FLAG*`。
- 管理门户登录/JWT 类另见 `../../web-auth-access/knowledge/oauth-jwt-test.md`。

## 四、云存储网关 / 身份联邦

真实链路示例：注册 → `/api/config` 泄露 `flag_bucket` → 上传自建 JWKS 到 public share（jku 必须指向站内允许前缀）→ 自签 HS256 token（claim `group=ops`）→ `/api/sts/exchange` 换 STS → 读 `terraform/prod.tfstate` 得对象存储 root 凭据 → 读敏感桶（凭据/备份/配置）。

要点：
- jku/JWKS 的可控性决定能否自签；`oct` 类型 key 常可用 HS256。
- tfstate / `.env` / k8s secret 是"凭据到凭据"的跳板。

## 五、验证与假点

- 只列出公开桶 = 假点；必须读到内部对象内容。
- 只拿到自身前缀权限 = 假点。
- 元数据 403/代理白名单 = 假点（换层后仍 403 才停止）。
