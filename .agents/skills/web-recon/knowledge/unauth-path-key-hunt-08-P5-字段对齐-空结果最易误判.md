# P5 字段对齐（空结果最易误判）

> 来源：CkSKILLS v1 `unauth-path-key-hunt` §P5 字段对齐（空结果最易误判）（迁移至 v2 知识块）

1. GET 目标方法 → 吃 405，改 POST
2. POST `{}` → `data:[]` 说明已进控制器
3. 明文关键字 / 错字段名 / 对字段名+密文 三组对照
4. 从**同类加密接口**抄字段名（改密接口用的字段名，查询多半沿用同一个）

示例（字段名错了会像没洞）：

| body | 常见结果 |
|---|---|
| `{}` | 200 `[]`（无鉴权） |
| `{title: 密文}` | `[]`（缺绑定） |
| `{title, uuid}` | `[]`（名错） |
| `{title, <业务>Uuid}` | 非空列表 |

**通过门：** 至少一种变体能把 `[]` 变成非空，或错误信息给出参数名。否则只写「接口暴露，危害未证实」。

路径对齐之后的全方法/BOLA/分页遍历交给 `api-protocol-security`。
