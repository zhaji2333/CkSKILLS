# 四、分工矩阵（什么时候用哪个）

> 来源：CkSKILLS v1 `asc-fast-hunt` §四、分工矩阵（什么时候用哪个）（迁移至 v2 知识块）

| 场景 | 用什么 | 原因 |
|---|---|---|
| 大包想知道有没有硬编码密钥/接口 | **本技能** `findrefs` | 秒级，零预处理 |
| 只想看组件面/权限/scheme | **本技能** `getmanifest` | 出全量 XML，不反编译 |
| 知道包名、类名被混淆不好猜 | **本技能** `listclass --prefix` | 只列定义，不反编译 |
| 已知类名，想看实现 | **本技能** `getclass` | 0.1s，够读逻辑 |
| 找某 Service/Activity/接口的所有子类（缩小组件面） | **本技能** `findrefs extends/impl` | 0.1.2 新增，直接查继承/接口表 |
| 需要 smali 指令级确认（Java 反编译失真时） | **本技能** `disassemble` | 0.1.2 新增，按需反汇编单类 |
| 只想看 1–2 个类、不想付全量成本 | **本技能** `getclass` / `disassemble` | 141–303ms/类；JADX 单类 6s–1m32s + 1–13GB |
| 要把几十~上百个 APK 一起 triage | **本技能** + 2.4 批量编排 | 单包 36–141MB、0 磁盘，可并行 |
| **小包（<20MB）任何环节** | **直接 JADX 全量** | 4.4MB 包 JADX 仅 5.87s，本技能省不下时间，白折腾 |
| 加固壳（stub/壳 so） | `apk-reversing` | 真代码不在 DEX，本技能搜不到 |
| 脱壳后的 dex 要检索 | **本技能**（打包成 zip 后） | 见"坑"第 2 条 |
| 混淆严重、需跨类数据流/调用图 | `apk-reversing` 全量反编译 + JADX | DAD 类型不可信，推理会歪 |
| **要查 res/（file_paths.xml、network_security_config、strings.xml）** | `apk-reversing` apktool/JADX | 本技能资源层为零 |
| **共现模式搜索**（`startActivity.*getParcelable` 等） | JADX 产物 + `grep -rE` | 引用表查询无法表达 |
| **报告取证截图** | `apk-reversing` JADX 产物 | DAD 输出寄存器级 + 类型错误，不能当证据 |
| 组件安全深挖 + 动态验证 + PoC | `android-security-audit` | 本技能只定位不验证 |
| 漏洞定级与报告成稿 | `../../../../rules/15-hunting-mindset.md`（六问）+ `../../../../rules/40-evidence-report.md`（定级/成稿） | MD 四段式 |

**成本对比（官方基准）**：59–352MB 包上，搜索 **322ms–1.597s**、单类反编译 **141–303ms**、内存 **36–141MB**、**磁盘 0**；同档 JADX 是 20s–8m2s（352MB 直接 OOM）、6s–1m32s、1–13.2GB、119–322MB 落盘。搜索快 **62–302×**、单类反编译快 **38–304×**、省内存 **28–96×**。本技能全流程（Manifest + 5 组关键词 + 读 10 个类）通常 **1 分钟内**跑完。

**定位升级**：ASC 不只是"搜索器"，它是**按需反编译引擎**——单类 `getclass`/`disassemble` 141–303ms，完全能在"只想知道这个类干嘛"时替代 JADX（6s–1m32s + 1–13GB）。边界不变：**DAD 类型不可信、无资源层、不能取证**。

**但这不是"全量替代 JADX"**：本技能回答**"在哪里、大致是什么"**，JADX 回答**"确切类型、怎么流、能不能用在报告里"**。实用阈值——

- **小包（<20MB）**：直接 JADX 全量也很快（4.4MB 只要 5.87s），快筛收益有限；但**批量几十个包**时 ASC 的零磁盘/低内存优势才开始显现
- **大包（>100MB）**：先本技能秒级定位，命中后再让 JADX 只精读相关部分——68MB 就要 39s + 7GB，352MB 级 JADX 直接 OOM
- **任何需要资源层/数据流/报告取证的环节**：无论包大小都回 `apk-reversing` 全量产物
