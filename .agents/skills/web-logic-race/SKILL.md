# web-logic-race — 业务逻辑与并发竞态专项

## 何时调用

- 支付/下单/退款/提现
- 优惠券/积分/红包/会员/订阅
- 库存/秒杀/抽奖/邀请
- 审批/工单/状态流
- 并发/重放/幂等

## 30 秒分诊

1. 先建业务状态机与角色矩阵（谁能做什么、状态怎么流）
2. 列金额/数量/状态/时间/身份 五类可控参数
3. 单次逻辑：改金额/数量/状态/身份
4. 并发：同一资源两请求同时发，看是否破坏不变量

## 首枪顺序

- 下单只传 product_id：服务端不校验应付金额 → 直接买
- 数量/价格负数、小数、0 元、超大数、精度截断
- 优惠券：重复领取/叠加/复用/并发
- 退款/提现：金额可改、负数、并发多退
- 订单状态跳变：未支付→已支付（改状态参/伪造回调）
- 并发抢最后一件/最后一张券（竞态）
- 审批越级/改审批人 id/跳过节点
- 邀请拉新：自邀/批量注册/改邀请人
- 导出/批量接口：改分页大小/换他人 id
