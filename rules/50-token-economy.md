# rules/50 — 上下文节流与加载纪律

> 常驻层已薄化，改为按需加载。目标：单题/单轮加载内容 ≤ 25KB。

## 加载顺序（不许跳步）

```
线索板（开工必读，只读 0/1/4/6 节）
  └→ 战法索引-*.md（只读相关的那一张，一行一枪）
      └→ 对应技能包 SKILL.md（≤4KB，先看"何时调用/30 秒分诊"）
          └→ knowledge/ 小块（≤12KB，只开指针点名的那块）
```

## 禁止

- 通读整个知识库 / 一次加载多个技能包（最多主包 + 1 个辅包）
- 读 >12KB 的整篇（先读点名节）
- 同一块重复读（结论写进线索板，不要靠记忆）
- 引用不存在的文件路径（引用前先确认磁盘上真实存在）
- 把技能正文原样复述进回答（要提炼成动作）

## 出口

- 每读完一块：把可执行结论写入线索板（`§3 手法/§6 下一步`）或直接执行命令。
- 上下文吃紧时：保留线索板 + 当前焦点 + 下一步，丢弃原始长响应（原料进 `raw/`）。

## 预算基线（v2 设计值）

| 内容 | 目标 |
|---|---|
| `AGENTS.md`（常驻） | ≤6KB |
| `rules/*`（单篇） | ≤3KB |
| 技能包 `SKILL.md` | ≤4KB |
| knowledge 小块 | ≤12KB |
| 单轮加载总量 | ≤25KB |
