# rules/60 — 范围、迭代与线索板

> 线索板是**单目标状态台账**；战法索引是**全局战法**。两者不许混写。

## 两种范围模式

### 锁面（固定资产 / 文档 / 清单 / 明确范围）

- 清单内全部可测资产都要过一遍；同皮系统只留 2–3 个代表（登录壳/同模板不重复）。
- 用户标了"重要/优先"的先打那一组；标号顺序不等于优先级。
- 不偷换成全集团测绘（无授权范围外资产不打）。

### 自由跳（只给品牌/集团名，模糊目标）

1. 种子落盘（业务名/品牌/根域/全资子公司）→ `hunts/<目标>/SEEDS.md`
2. 一个种子闭环：搜 → 去重去废去非存活 → 活面挖完 → 才换下一个种子
3. 禁止一次搜完所有种子再挖；禁止问"要不要继续"；全 done 才汇报
4. 优质根域回灌：确认优质面后把"业务簇根域"加入队列

## 线索板协议

- 位置：`hunts/<目标短名>/CLUEBOARD.md`（任务根与分夹见 `rules/65-task-dir.md`；模板 `templates/CLUEBOARD.template.md`）；原料 `raw/`
- 开工：读 §0 当前焦点 / §1 Host / §4 已证伪 / §6 下一步 → 第一任务 = 当前焦点
- 挖中：新 Host→§1，路径/状态→§2，密钥/字段→§3，无效/405/空→§4，下一步→§6，覆盖度→§7
- 收工：更新当前焦点；假设 >5 条删最弱或标证伪；板 >200 行时原料搬 `raw/`
- 多 agent：子代理**不写板**，收工交 `dig/<角色>/SYNC.md` 回灌块；Lead 合板并记 `§8 同步日志`。→ `rules/66-agent-teams.md`
- 状态四选一：`假设` / `已证伪` / `已证实` / `待打`
- **凭证/密钥/token/会话/内部地址存原文**（供继续利用）；真实用户 PII 按 `rules/20-min-harm.md` 最小化

## 续挖 / 换会话

- 先读线索板（别从主站 JS 重开一局）；已证伪项直接跳过；否定证据优先保留。
- 交接一句话：**丢板等于没挖过。**
- 多 agent 任务续跑：先 `python3 tools/clueboard_sync_check.py hunts/<目标>`，有 FAIL 先合板再换会话。
