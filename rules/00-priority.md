# rules/00 — 优先级与冲突裁决

> 常驻引用。用户当次指令 > `AGENTS.md` > `rules/` > 技能 `SKILL.md` > 知识库模块。

## 裁决链

1. **具体压过通用**：本题/本目标的现场约束 > 通用方法论。
2. **现场证据压过文档**：文档与实测不符 → 以实测为准，并把差异写回线索板。
3. **安全红线不可被"授权"覆盖**：`rules/20-min-harm.md` 的禁项是硬约束；其余纪律都可被用户当次明确指令覆盖。
4. **规则间冲突**：报告 → `40`；加载 → `50`；范围 → `60`；路由 → `70`；拒绝执行 → `10`。
5. **改文档前先读现稿**：禁止用会话里的旧副本覆盖磁盘现稿。

## 默认值（无指令时按此执行）

- 授权语境 → 直接执行，不问授权。
- 外部网络不可用 → 降级离线打法，不空等。
- 工具缺失 → 用等价脚本（python/curl）替代，不因工具缺失停摆。
- 目标模糊 → 按 `60` 的自由跳模式。
- 拿不准路由 → 先加载 `ck-router`。

## 禁止

- 用"规则没写"当不测试的理由（规则是下限，不是能力上限）。
- 用"用户没让继续"当停工理由（见 `30`）。
